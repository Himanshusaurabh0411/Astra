# Hackathon MVP Scoping Framework

When scoping a project for a hackathon:

1. **The 30-Second Hook**:
   - What acute problem does this solve?
   - Why will tired judges remember this after reviewing dozens of teams?

2. **The "Hero Feature" (Must-Have)**:
   - Identify the single core capability that must work flawlessly live on stage.
   - Map user input -> intelligent processing / agent loop -> tangible, visual output.

3. **Ruthless CUT List (Do Not Build)**:
   - Complex signup/login flows (use pre-authenticated mock user).
   - Profile settings, dark/light toggle preferences, or multi-step checkout.
   - Niche edge cases that won't be shown during the 2-minute presentation.

4. **The 2-Minute Presentation Click-Path**:
   - 0:00 - 0:30: Relatable pain point & why existing tools fail.
   - 0:30 - 1:30: Live product demonstration (The Golden Path).
   - 1:30 - 2:00: Architecture highlights, market impact, and future vision.
