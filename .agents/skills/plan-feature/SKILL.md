# Feature Planning Workflow

1. **Clarify Scope & Inputs**:
   - Understand the core goal, user interactions, and dependencies.
   - Clarify edge cases and failure modes upfront.

2. **Explore Existing Codebase**:
   - Inspect existing components, schemas, or routes without mutating them.
   - List files to create and files to modify.

3. **Produce Implementation Plan**:
   - Write a structured plan detailing components, state management, and step-by-step implementation order.
   - Define exact verification criteria (how to verify it works).

4. **Wait for Approval**:
   - Present the plan to the user for feedback before beginning implementation.
